# 60-second day-in-the-life video script

**Purpose:** Internal craft sign-off + App Review optional attachment.  
**Device:** Physical iPhone, clean status bar, entitled demo seat, **no PHI**.

## Shot list (record in one continuous take if possible)

| Sec | Screen | Action | Voiceover / caption (optional) |
|-----|--------|--------|--------------------------------|
| 0–5 | Logged-out Home | Dual doors visible | “Two clear offers” |
| 5–12 | Login → Entitled Home | One mission card | “One next action” |
| 12–22 | Command | Open hub / empty or next visit | “Command Center” |
| 22–38 | Tools → Objection | Type sample objection → Generate | “Field-ready talk track” |
| 38–48 | Result | Copy or share visible | “Finish the job” |
| 48–55 | Account | Status chip + value receipt | “Same seat as web” |
| 55–60 | Home | Mission still clear | “Back to the field” |

## Sample objection (safe)

> “We’re not ready for hospice yet — the family wants to keep trying.”

## Rules

- Fake facility names only  
- No real patient data  
- Prefer dark product mode  
- Horizontal capture OK for internal; vertical for store social  

## Storage

Save as `artifacts/spartan-coaching-mobile/store/videos/day-in-life-YYYYMMDD.mp4` (git-lfs or external; do not force large binaries into git without LFS).
