# Experience Principles (P1–P10)

1. **One next action** — one emphasis mission card; secondaries quiet.  
2. **Field conditions** — one hand, 90s, ≥44pt targets, sticky result CTAs.  
3. **Product grammar** — Mission → Command → Tool → Result → Account (both surfaces).  
4. **Subscription honesty** — designed shells for out / locked / trial / active / expired / company.  
5. **Visual restraint** — midnight navy; Spartan red for primary/focus only; no emoji icons.  
6. **Finish states** — title, body, copy/share/save, disclaimer on generative tools.  
7. **Connected, not clever** — entitlement refreshes after web checkout; explicit web handoffs.  
8. **Trust & clinical** — vault never wears marketing chrome.  
9. **Motion** — 150–300ms; haptics respect Reduce Motion.  
10. **Proof** — device + seat smoke required for premium claims.

**PR review:** reject screens that violate more than one principle without a written waiver.
