---
name: Public product screenshots
description: Trust and disclosure rules for product imagery on public Spartan Coaching pages
---

Public marketing images must contain only customer-facing product surfaces. If a source capture includes an administrator identity, role, navigation, or internal controls, create a sanitized derivative whose pixels permanently exclude them.

**Why:** CSS crops still ship the complete source image. Visitors can open the asset directly or remove the crop, exposing internal surfaces and weakening product trust.

**How to apply:** Review the actual image file before importing it. Use a destructively cropped or separately captured customer-role asset, then verify both the file itself and desktop/mobile rendering.
