---
name: Spartan web visual modes
description: The durable relationship between public, editorial, and authenticated web presentation
---

Spartan Coaching’s web identity uses one shared performance language. Cinematic black staging remains intentional, while public content and authenticated tools both consume the visitor’s persisted semantic appearance.

**Why:** Applying the light public tokens directly to the existing navy workspace made workspace labels and navigation unreadable. The dark workspace must define its own foreground, muted, card, popover, input, sidebar, and border semantics.

**How to apply:** Use black only for concentrated brand moments such as the unobstructed film. Public page surfaces, navigation, footer, cards, dialogs, and conversion panels must consume semantic tokens and preserve the selected appearance across navigation and reload. Keep full desktop navigation only where it fits and explicit Search/Menu controls below that breakpoint. Render key hero copy as live HTML outside the video rather than baking it into frames. Use one condensed display family with restraint, one readable body family, and mono only for compact utility copy. Interior public pages must use distinct compositions and substantial decision-support content rather than repeating oversized all-caps slogans, sparse cards, or generic centered heroes. Consulting must preserve the complete supportable offering catalog rather than collapsing it into umbrella categories. Authenticated screens remain inside the workspace command scope. Preserve validated saved appearance choices across first paint and React initialization; route ownership must never replace the selected theme.
