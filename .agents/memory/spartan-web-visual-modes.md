---
name: Spartan web visual modes
description: The durable relationship between public, editorial, and authenticated web presentation
---

Spartan Coaching’s approved public direction is Field Intelligence: documentary and human, with field green, mineral paper, rust, editorial serif typography, authentic imagery, operational detail, asymmetric compositions, and restrained motion. Authenticated tools remain inside their separate dark command scope.

**Why:** The user explicitly rejected generic SaaS layouts and selected Field Intelligence after comparing three high-fidelity directions. Applying light public tokens directly to the existing navy workspace also made workspace labels and navigation unreadable, so the dark workspace must retain its own complete semantic palette.

**How to apply:** Use black only for concentrated brand moments such as the unobstructed film. Public page surfaces, navigation, footer, cards, dialogs, and conversion panels must consume semantic tokens and preserve the selected appearance across navigation and reload. Keep full desktop navigation only where it fits and explicit Search/Menu controls below that breakpoint. Render key hero copy as live HTML outside the video rather than baking it into frames. Use the editorial serif for expressive headlines, a readable sans for body copy, and utility lettering only for compact labels. Interior public pages must use distinct compositions and substantial decision-support content rather than repeating oversized all-caps slogans, sparse rounded-card grids, dossier/ledger framing, or generic centered heroes. Consulting must preserve the complete supportable offering catalog rather than collapsing it into umbrella categories. Never fabricate client proof, metrics, logos, credentials, or founder facts. Authenticated screens remain inside the workspace command scope. Preserve validated saved appearance choices across first paint and React initialization; route ownership must never replace the selected theme.
