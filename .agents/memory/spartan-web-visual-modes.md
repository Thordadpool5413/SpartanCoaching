---
name: Spartan web visual modes
description: The durable relationship between public, editorial, and authenticated web presentation
---

Spartan Coaching’s public direction uses a restrained private-advisory system: warm paper, near-black, deep garnet, editorial serif display type, readable sans body type, authentic imagery, operational detail, and restrained motion. The homepage film must remain the full-screen primary experience below the navigation. Authenticated tools remain inside their separate dark command scope.

**Why:** The user explicitly rejected both generic SaaS layouts and the green/rust Field Intelligence rebuild. A later black/red all-caps version was also too aggressive to feel trustworthy or expensive. Applying light public tokens directly to the existing navy workspace made workspace labels and navigation unreadable, so the dark workspace must retain its own complete semantic palette.

**How to apply:** Keep the homepage film full-bleed and viewport-filling below navigation; never replace it with a split, contained, or below-copy video. Use a stable directional scrim, live HTML copy, mobile-safe composition, reduced-motion behavior, and an always-available playback control. Use dark backgrounds only for concentrated brand moments. Public page surfaces, navigation, footer, cards, dialogs, and conversion panels must consume semantic tokens and preserve the selected appearance across navigation and reload. Keep full desktop navigation only where it fits and explicit Search/Menu controls below that breakpoint. Use the editorial serif for expressive sentence-case headlines, a readable sans for body copy, and utility lettering only for compact labels. Interior public pages must use distinct compositions and substantial decision-support content rather than repeating oversized all-caps slogans, sparse rounded-card grids, dossier/ledger framing, or generic centered heroes. Consulting must preserve the complete supportable offering catalog rather than collapsing it into umbrella categories. Never fabricate client proof, metrics, logos, credentials, or founder facts. Authenticated screens remain inside the workspace command scope. Preserve validated saved appearance choices across first paint and React initialization; route ownership must never replace the selected theme.
