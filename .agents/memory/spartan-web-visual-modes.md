---
name: Spartan web visual modes
description: The durable relationship between public, editorial, and authenticated web presentation
---

Spartan Coaching’s web identity uses one shared performance language with two complete surface modes: cinematic black staging plus warm ivory/ink/red public content, and a self-contained dark command mode for authenticated tools.

**Why:** Applying the light public tokens directly to the existing navy workspace made workspace labels and navigation unreadable. The dark workspace must define its own foreground, muted, card, popover, input, sidebar, and border semantics.

**How to apply:** Use black for concentrated brand moments, warm ivory for readable journeys, and Spartan red only for marks, field lines, emphasis, and primary action. Keep public navigation opaque, with full desktop navigation only where it fits and explicit Search/Menu controls below that breakpoint. Render key hero copy as live HTML rather than baking it into video frames. Use one condensed display family, one readable body family, and mono only for compact utility copy. New authenticated screens should live inside the workspace command scope and consume semantic tokens. Preserve validated saved appearance choices across first paint and React initialization. Public compatibility rules must preserve intentional red and ivory hero contrast rather than flattening them into surrounding ink.
