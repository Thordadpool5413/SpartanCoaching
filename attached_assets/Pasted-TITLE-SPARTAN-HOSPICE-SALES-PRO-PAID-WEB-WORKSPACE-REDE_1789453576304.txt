======================================================================
GOAL
======================================================================

Redesign and implement the COMPLETE PAID WEB WORKSPACE for Spartan Hospice Sales Pro.

This is a full product-system redesign of the authenticated WEB workspace.

It is NOT:

- a public website redesign
- a marketing-site redesign
- an iOS redesign
- an Expo redesign
- a backend rewrite
- a database redesign
- a route rewrite
- a static prototype
- a dashboard refresh
- a card refresh
- a simple theme change

The objective is to transform the paid web workspace into ONE coherent, restrained, precise, professional operating environment for hospice sales work.

The primary unit of experience is:

THE USER'S CURRENT OBJECTIVE
+
THE REAL WORK, CONTEXT, INTELLIGENCE, AND NEXT ACTION ATTACHED TO IT.

Every major screen should help the user answer:

1. What am I trying to accomplish?
2. What matters now?
3. What do I already know?
4. What information is uncertain?
5. What work already exists?
6. What can actually be resumed?
7. What action is genuinely supported?
8. What happens next?
