# Spartan Coaching Home Acceptance Specification

## Approved public target

The binding visual target is Figma file `p3WMv207TPMNY2XmGm0E0H`, node
`33:13`, named `Public Home`. The frame is 440 by 956 points and is reviewed on
an iPhone 17 Pro Max. Older generated Home images in this repository are not
binding references.

## Product purpose

Home is a personal field guide. It is not a CRM, a feature directory, an
administration dashboard, or a subscription advertisement. A visitor should
understand the product before paying. A member should understand the next
useful action within ten seconds and reach it within three taps.

## Public Home hierarchy

1. Transparent red helmet as a compact icon
2. Spartan Coaching wordmark rendered beside the icon
3. Sign in action
4. Hospice sales field guide label
5. Clear outcome promise
6. Plan the conversation path
7. Practice with Spartan Coach path
8. Guided experience action
9. Exact Standard and Elite weekly prices with Apple purchase explanation
10. Separate human consulting entry
11. Five destination native tab bar

## Signed in Home hierarchy

1. Compact helmet identity and Account access
2. Personal greeting
3. One clear preparation question
4. Primary conversation planning action
5. Practice action appropriate to the member's access
6. Explore entry
7. Current private commitment
8. Optional team leadership context
9. Guided tour entry

## Brand rules

The transparent red helmet is the compact native icon. It never appears on a
black tile and is never cropped by a decorative shell. On Home it is paired
with the Spartan Coaching name so it is not presented as the complete company
logo.

The supplied distressed Spartan Coaching logo remains the full brand asset for
approved full logo placements. It is not substituted with the helmet alone.

The light appearance uses warm white, deep navy, Spartan crimson, charcoal,
and restrained cool gray. The dark appearance retains the same hierarchy using
the approved deep navy palette. Pure black is not the primary app surface.

## Behavior rules

The preparation action opens the native Playbook experience. Objection
practice opens the native Objection experience or private Coach when the member
has Elite access. Commitment continuation opens Coach or the native Weekly Plan
based on access.

Visitors can tour and compare Standard and Elite before account creation.
Apple purchase happens before account creation. Consulting remains separately
contracted. The Account control opens Account. Every control provides native
feedback and has a readable accessibility label or visible text.

## Acceptance gate

The coded Home screen must be captured at the same 440 by 956 point viewport
and state as Figma node `33:13`. The Figma reference and device capture must be
reviewed together. Any material mismatch in helmet treatment, hierarchy,
spacing, typography, color, navigation, or action behavior blocks acceptance.

Automated tests support the gate but do not replace visual comparison on the
rendered app.
